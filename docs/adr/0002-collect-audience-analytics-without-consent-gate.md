# เริ่มเก็บ Audience Analytics โดยไม่มี Consent Gate

ตามคำสั่งของเจ้าของระบบ การเก็บ Viewer Journey, attribution, Active Time และ Behavioral Persona จะเริ่มโดยไม่รอ consent จากหน้าเว็บไซต์ แม้มีทางเลือกให้เริ่มหลัง consent ก็ตาม การตัดสินใจนี้เป็นขอบเขตความรับผิดชอบด้านฐานกฎหมายและ Privacy Notice ของผู้ดำเนินงาน และระบบจะลดข้อมูลที่เก็บโดยไม่บันทึก IP จริงหรือ query string ที่ไม่ได้รับอนุญาต
